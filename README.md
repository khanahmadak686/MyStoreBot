# 🛒 My Kirana Store - Ultimate E-commerce Bot

A powerful, fast, and fully automated E-commerce Telegram bot designed to digitize local Kirana stores. With features comparable to Blinkit or Zepto, this bot allows customers to order groceries from the comfort of their homes.

## 🚀 Key Features

* **Smart Product Catalog:** Categorized browsing with search functionality.
* **Inventory Management:** Automatic stock tracking with "Out of Stock" alerts.
* **Verified Ordering:** Telegram contact verification to prevent fake orders.
* **Customer Support:** Direct chat interface between customers and store admins.
* **Wallet & Cashback System:** Earn 5% cashback on every order, stored in an integrated Kirana Wallet.
* **Viral Referral Program:** A "Refer & Earn" system to scale your business organically.
* **Rider Dashboard:** A dedicated mobile-friendly interface for delivery partners to manage and track active orders.
* **Admin Control:** Real-time order notifications, automated bill generation, and sales report downloads.

## 📦 Tech Stack

* **Backend:** Node.js, Express.js
* **Interface:** Telegram Bot API
* **Database:** JSON-based persistent storage
* **Hosting:** Deployed on Render with Webhook integration for high stability.

## 🛠️ User Workflow

1.  **Launch:** Users trigger the bot with `/start` to see the shop menu.
2.  **Browse & Select:** Choose products from categories and add them to the cart.
3.  **Secure Checkout:** Choose between Home Delivery or Store Pickup. Verified contact and address capture ensure reliable service.
4.  **Payment & Rewards:** Complete payments via UPI or Cash. Automatic cashback is credited to the user's wallet for future use.
5.  **Tracking:** Admins update order status (Packed/Out for Delivery/Delivered), and customers get real-time updates.

## 📈 Deployment Status

The system is currently running on **Render** using a stable Webhook architecture to avoid polling conflicts.
